# Химпрактикум — Точность в химии

Интерактивный урок по физической химии на русском языке. Три главы знакомят со стандартной записью чисел, значащими цифрами и правилами округления. В конце есть шесть задач с объяснениями. Результаты сохраняются в браузере.

[Открыть урок на GitHub Pages](https://komhujsob.github.io/chem-precision/)

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Публикация

Чтобы опубликовать проект на GitHub Pages, добавьте файлы в корень репозитория. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
